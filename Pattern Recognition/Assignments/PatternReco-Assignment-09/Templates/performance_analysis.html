Theoretical Frameworks & Comparative Paradigm Analysis

1. Parzen Window Density Estimation (Assignment 09)

Estimates the continuous class-conditional probability density function \(p(\mathbf{x}|\omega_j)\) directly from data samples without assuming an underlying parametric distribution:

\[ p(\mathbf{x} | \omega_j) = \frac{1}{N_j V_n} \sum_{i=1}^{N_j} \varphi\left(\frac{\mathbf{x} - \mathbf{x}_{ji}}{h}\right) \]
  • Hypercube Window: \(\varphi(\mathbf{u}) = 1\) if \(\max_k |u_k| \le 0.5\), else \(0\). Fast counts in \(V = h^d\); detects empty regions (\(\sum k_j = 0\)).
  • Gaussian Window: Smooth mixture of spherical Gaussians. With small \(h\) or high dimensions \(d\), underflow is prevented via the Log-Sum-Exp trick: \[ \ln p(\mathbf{x}|\omega_j) = -\ln N_j - \frac{d}{2}\ln(2\pi) - d\ln h + \text{LSE}\left(-\frac{\|\mathbf{x} - \mathbf{x}_i\|^2}{2h^2}\right) \]
  • Optimal Window Width \(h^*\): Balances bias (large \(h\), oversmoothed) and variance (small \(h\), spiky/underflow).

2. Ho-Kashyap Linear Classification Procedure (Assignment 08)

Finds a separating weight vector \(\mathbf{a}\) and margin vector \(\mathbf{b} > \mathbf{0}\) by minimizing squared error \(J_H = \frac{1}{2}\|Y\mathbf{a} - \mathbf{b}\|^2\):

\[ \mathbf{a}(k+1) = Y^\dagger \mathbf{b}(k+1), \quad \mathbf{b}(k+1) = \mathbf{b}(k) + 2\eta \max(\mathbf{0}, Y\mathbf{a}(k) - \mathbf{b}(k)) \]
  • Separability Diagnosis: Guarantees finite convergence if linearly separable. If \(\mathbf{e}(k) \le \mathbf{0}\) with \(\mathbf{e}(k) \ne \mathbf{0}\), rigorously proves linear non-separability!
  • Inference Speed: Extremely lightweight planar evaluation \(g(\mathbf{x}) = \mathbf{a}^T [1, \mathbf{x}]^T\).

3. Cross-Paradigm Comparison: Strengths, Complexities & Ideal Use Cases

Parzen Window

Non-Parametric Density

Arbitrary non-linear boundaries; full posterior distribution \(P(\omega_j|\mathbf{x})\); sensitive to window width \(h\); log-sum-exp ensures numerical stability.

Ho-Kashyap

Linear Discriminant

Optimal linear margin; formally detects linear separability; instantaneous inference \(\mathcal{O}(d)\); restricted to hyperplanar boundaries.

KNN (Elbow Method)

Instance-Based Lazy

Zero training phase; tunes \(K^*\) via elbow curve; transparent neighbor explainability; test latency scales as \(\mathcal{O}(Nd)\).

Gaussian Naive Bayes

Parametric Generative

Estimates mean \(\mu\) and variance \(\sigma^2\) per feature; highly resilient to small sample sizes; assumes feature conditional independence.
